## 方法对照的保存约束

`POST /api/projects/:id/derive` 新增 `intent=edit_module`，请求指定 source revision、slot、module_id 和候选完整身份哈希。服务器保留数据、年份、参数、网络、求解器、其他模块和扩展；需要同时改变这些配置的候选会被拒绝，并提示另建多方法 Study。

候选确认只取本次请求；源 Study 中曾选过候选而残留的确认不能自动沿用。兼容性响应绑定来源修订与候选身份；用户勾选确认后，确认框保持可见，但保存仍等待新响应。创建的新 Study 有方法变更记录和基线 Runs 入口，保存不启动 Run。

派生在暂存后、发布前再次核对来源配置、输入文件、原模块图、候选身份和新图。本地文件在校验过程中漂移或保存失败时，清理暂存与预留目录；不修改原 Study。旧 Run 的冻结身份和历史追溯保持原机制。
