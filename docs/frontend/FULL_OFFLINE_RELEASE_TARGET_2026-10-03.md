# VALUE 完整离线安装包发布目标

2026-10-03，依据用户本轮决定：先交付自带运行环境的完整安装包，以此作为后续发布目标。此前依赖外部 Python/Node 的小包保留为历史验收材料，不再作为默认下载目标。

## 用户体验与产品边界

VALUE 主体包含前端、后台、模型、两个 VALUE 101 教学数据包、私有 Python、Node 和锁定的科学依赖。下载完整包之后，安装、启动及运行随附教学任务均不需要网络或预装 Python/Node。安装在用户可写目录，不写系统 PATH，不覆盖用户已有研究。私有环境随发行版本固定，运行时文件纳入完整性清单。

主体提供 Windows x64、Linux x64、macOS Intel、macOS Apple Silicon 四个包。Linux 要求 glibc 2.28、GLIBCXX 3.4.25、内核 4.18 或更新；Windows 10 或更新；macOS 15 或更新。macOS 门槛来自既有锁定 CBC 依赖的原生 wheel，不能仅按 Python 或 Node 的最低要求宣传支持范围。所列最低门槛来自发行元数据，不等同于这些系统版本均已实机测试。

2026-10-04 更新：此前称为 VALUE-single 的产品是 Electrace 私有差分优化引擎，不属于 VALUE，也不纳入本发行目标或 Apache 授权。此前有关其公开封装和发行的计划已取消。

## 实现与来源

- 复用已通过四角色验收的应用归档，应用 2,030 个文件保持逐字节一致。来源归档 SHA256：`91f655ab65974bd90f150034cecb5dc12dcc0596f1962d990e54e5b04b6b6b85`；应用文件身份：`6c74f51a176ea238141dd3a10cd24e966b4dd3fc82615444f467e58e819b0010`。
- `scripts/prepare_private_runtimes.py` 准备平台对应的运行时和 wheel，校验固定下载 SHA、目标 Python/平台 tags、依赖闭包并输出逐文件与许可清单。禁止从研究中的原环境复制运行时。
- `scripts/build_full_desktop_installers.py` 校验已验应用归档及准备后的运行时清单，组合平台安装入口，输出四个归档、SHA256SUMS 与 build manifest。
- `packaging/desktop-local/desktop_value.py` 支持私有运行时模式；完整包拒绝外部 Python/Node 覆盖。临时目录内验证与初始化，最终收据指向安装目录，安装后启动不再依赖解压源。
- 安装、运行、诊断使用包内解释器，隔离用户 Python 包；应用执行身份与原模块/扩展契约继续生效。Mac/Windows 原生验收及签名、公证单独记录，不能由 Linux 或归档检查推导。

## 必要验收

1. 四个归档逐文件校验、源码一致性、运行时架构与 wheel 兼容性检查；确认没有混入用户 Study、Run 或新测试输出。
2. Linux 最终归档全新解压，在无外网、宿主 Python/Node 不可调用的隔离环境安装、诊断、启动；移走解压源后仍使用已安装环境。
3. 安装后新建执行记录：教学基线及四角色既定短任务。只复用之前通过界面制作的隔离输入夹具，不复制历史 Run；模块及扩展重新通过正式安装接口安装。核对五维比较、60 MWh 需求、73 GBP/MWh 声明报价、observer 年份和输入摘要。
4. VALUE 发行范围仅包含本项目主体；Electrace 私有引擎不进入公开源码或安装归档。
5. 四角色工作流程及浏览器指引已有前次验收；本轮重点是打包后运行环境，浏览器补查已安装版本的结果可读性。无需重跑全年或十年科学模型。

隔离环境仍使用宿主内核及基础系统库；这不是全新的 Windows/macOS 虚拟机，也不覆盖全部 Linux 发行版。验收结果见交付目录的 `platform-validation.json` 与 `acceptance-results.md`。

## 发布顺序与未完成事项

先固定完整包及哈希和对应源码快照，再按原 GitHub 上传计划确认权利、版本与仓库，创建受审的 Release 附件，最后将实际下载 URL 回填现有官网。安装包不提交进 Git 历史，网站不承载本地模型服务。主包仍保留原科学发布边界；私有引擎不纳入 VALUE 的公开发行。

本轮不执行 GitHub 推送、线上发布、代码签名、公证或已有研究迁移。当前安装器只接受空目录；升级采用旁路安装，已有 Study/Run 自动迁移另行施工，不在说明中承诺覆盖升级。Windows/macOS 必须在对应系统验收后才能标为稳定支持。
