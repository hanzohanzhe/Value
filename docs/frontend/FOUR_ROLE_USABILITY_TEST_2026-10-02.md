# 四角色前端可用性实测

日期：2026-10-02。对象：f1c89a1 Linux 交付版的独立安装。

## 验收约定

使用 computer use 实际点击，只依据前端提示、内置 Read me、前端下载文件中的说明完成业务步骤。环境启动、准备用户输入文件、记录证据可使用本地工具；不得使用后端接口或实现代码补齐缺失的操作指引。发现问题先记录，不把工程师协助后的结果混为首次通过。原研究工作区不作为测试写入对象。

每条路径只做一个有实际产出的任务，运行采用界面允许的最小检查范围。这验证操作闭环，不验证全年结论或模型科学正确性。作者路径若明确要求本地编辑，应记录依赖及说明是否足够。

## 预先确定的任务与清单

| 角色 | 任务 | 必须看到的最终证据 |
|---|---|---|
| reproduce from existing data | 从 VALUE 101 教学基线创建独立复现研究并运行 | 来源、独立 Study、明确运行、结果和基线比较；输入/方法/范围一致性可核对 |
| add your new data | 复制基线基础包，修改一项需求输入，以原方法运行 | 数据映射/校验、独立数据包和 Study、原方法保留、输入差异及结果可读 |

| add new function to VALUE | 新增一个按年输出输入身份摘要的 observer 功能 | 提案验证、安装、独立 Study 启用并绑定数据、明确运行、Inspect 中的摘要产物 |

每条任务逐项记录：

- [ ] 从 Home 找到角色入口和所需说明。
- [ ] 按说明准备必要输入；记录所有猜测或额外帮助。
- [ ] 完成配置，保存独立 Study，保存不自动运行。
- [ ] 看懂校验/兼容性信息，明确发起最小运行。
- [ ] 找到任务要求的结果，理解来源及限制。
- [ ] 对照源研究，确认没有改写原配置或结果。

结论分为通过、部分通过、阻塞。只下载模板或安装包不算通过；使用未公开的接口、实现知识或人工修复后成功，必须单列协助步骤。

## 实测记录

### 1. 结论与执行边界

四条入口均可找到，但本轮不能判定“四类用户均能完成工作”：**R1 部分通过，R2 未通过，R3 阻塞，R4 在本次 observer 接线任务范围内通过。** 共创建并明确启动 **5 个 Run（含教学基线）**，其中 4 个完成、1 个失败。完成状态不能替代任务验收，更不能替代科学验证。

保留以上预先任务与验收条件。实测记录额外使用“未通过”表示操作能走完、但输出违背任务约束的情况；“阻塞”表示目标运行未能完成。R2 与 R3 因而分别标记，未降低任何预定标准。

| 路径 | 判定 | 已取得的产物 | 未满足的条件或限定 |
|---|---|---|---|
| reproduce from existing data | 部分通过 | 独立 Study、完成的教学 Run、基线比较页面 | 参数与扩展配置为 `[null, null]`，不能确认完整复现条件 |
| add your new data | 未通过 | 独立包和 Study、已提交的数据映射、完成的 Run | 声明为 60 MWh/period 的需求实际按 30 MWh 执行；比较另缺配置身份 |
| Edit module | 阻塞 | 固定报价 73 的独立模块包、安装与预检通过、独立 Study、失败诊断 | 实际运行因模板缺少 `prepared_year` 失败，未取得新报价结果 |
| add new function to VALUE | 本次限定任务通过 | 已安装 observer、独立 Study/包、完成的短 Run、Inspect 年份与输入身份摘要 | 经数据复制绕行和界面内重新校验后完成；仅证明 observer 接线，不证明新物理算法 |

实际业务步骤全部由主测试者通过 CUA 点击前端完成，未以直接 API 请求或后端实现知识代替缺失的业务操作。作者文件助手使用用户指定的 **GPT‑6.1‑sol**：R3 仅依据前端下载 README 本地改价、更新作者元数据并打包，再回到 UI 安装；R4 仅解压并阅读前端生成的扩展及说明，**未本地修改扩展实现**。这是被记录的作者路径依赖，不是完全无协助的新用户样本。R2 的输入 CSV 也由本地工具准备。测试中没有修改产品、修补失败 Run、绕过 UI 的校验/安装或重写旧结果。

失败出现后另做只读诊断，以区分界面症状与实现原因；这份诊断不反向计入首次完成率。流程依据见[会话记录]([LOCAL_PATH_REDACTED])，原因与修复边界见[只读诊断]([LOCAL_PATH_REDACTED])。

### 7. 开发建议与复验门槛

以下是建议，不是已完成修复。先解决三项 P1，再对受影响任务以新身份重新验收。

### 8. 证据使用说明

[会话记录]([LOCAL_PATH_REDACTED])保留每条路径的 Study/Run/包身份及现场说明；四角色的文本、截图、CSV、作者 README 与安装包均保存在同一证据目录。已确认的三项 P1 原因集中在[只读诊断]([LOCAL_PATH_REDACTED])。

CUA 中 pressed 按钮被映射成 checkbox、部分 label 定位失败，以及下载事件超时但文件实际存在，均按工具定位/观测差异记录，不据此判产品阻塞。相反，配置证据缺失、单位不一致、模板生命周期异常与界面范围/校验滞后，均有实际 UI 或运行产物支持，应进入产品问题清单。
