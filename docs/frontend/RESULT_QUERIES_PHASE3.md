## 用户可见变化

Runs 的比较区增加五项冻结身份：基础与网络数据、模块方法、参数与扩展配置、执行年份、运行范围。分别显示一致、已改变或无法核实，可展开记录。数据包改名或创建新 snapshot ID 不被误报为数据变化；数据 SHA、方法源码身份或求解器设置改变则会显现。缺失或冲突的历史身份阻止受控比较和单因素归因，原有网络与弃电科学验证仍保留。

派生研究的来源提示可以列出属于该来源修订的 Runs，其他修订及无修订记录的 Runs 不会自动充当基线。仍可打开来源 Study 的全部历史 Runs，由用户明确选择对照。

VRE & curtailment 新增最终弃电 v2 查询卡片。用户选择 SQLite 或 compact 来源、年份、半小时时窗和页码。SQLite 使用只读查询；compact 仅提供真实保存的年度汇总，不假造逐时、区域和技术维度。旧的 PSM unused VRE 页面保留，二者定义分开展示。页面显示源文件哈希、容器 Run 的冻结快照、已记录的模块身份与缺失字段。

## 服务和组件边界

新增 `GET /api/runs/{id}/results/vre-curtailment`，响应为 `value.result-query/v1`。允许参数：`source=auto|sqlite|compact`、`resolution=annual|half_hour`、`year`、`period_from`、`period_to`、`limit`、`offset`。未知、重复、不合法字段明确失败；compact 请求逐时维度返回 `GF_RESULT_DIMENSION_UNAVAILABLE`。分页最多 500 行，默认界面 48 行。

SQLite 和 compact 使用同一最终弃电契约。年度必须满足完整运行年份集合和每年 17520 个时段；诊断运行年度值暂扣。逐期数值通过流式游标校核，不允许反向残差在年度加总后互相抵消。比例按汇总分子分母计算，新增与避免弃电分开保留；不改变模型物理算法。

选择 auto 时，有 SQLite 就查询 SQLite，损坏账本不会静默切换 compact。完成运行的来源在读取前后核对文件身份，活跃事务文件被拒绝；compact 解析与 SHA 来自同一份字节。来源自身记录的 Run ID 与外围容器身份分开，缺失来源字段不从当前 Study 或旁边 artifact 补造。结果的 reconciled 表示该契约下记录可核对，不等于历史环境已恢复或研究获得新的科学认证。

compact_results 导出新增保留 `model-output/network/vre-curtailment-attribution.json`。未扩大到代码或源输入导出。

`ComparisonWorkspace`、`ResultQueryPanel` 和 `BaselineRuns` 已从主页面拆出。比较和结果请求使用实际 AbortController、请求身份和响应范围校对；切换来源、Run 或范围后旧响应不能恢复旧结果。主页面集成使用不同组件 key，避免加载 Run 时残留空卡片。
