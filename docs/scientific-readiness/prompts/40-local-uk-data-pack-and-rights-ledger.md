# Prompt 40 — Convenient local UK data pack and redistribution ledger

This task may use the existing local sources and adapters. Do not require a public
redistributable archive to make local research convenient.

## Objective

Assemble one locally installable 25-role data pack from files already on this
computer, with source organization, object hashes, original source/publisher,
retrieval notes, adapter/mapping version and per-object redistribution status.

## Acceptance

- Local pack installs atomically and passes all semantic preflight checks.
- Data bytes are not duplicated unnecessarily; a manifest or local materialization
  is acceptable when it is most convenient.
- `local_use`, `redistributable`, `conditional` and `excluded` are distinct.
- No conditional UK object enters the public software/synthetic-data distribution.
