## 2 实现要点

### 2.1 S4：P5-06 物理运行成本（两轨通用）

- `operating = Σ gen_cost×出力 + Σ 进口价×进口 + 启动加价 + 记录的缺电×VoLL + 储能循环磨损`。
  - `gen_cost` 是机组的运行成本（含燃料、碳价和 unit_time_cost），不乘 bid multiplier，因此 `market.bid_multiplier` 不改变物理成本。
  - 启动加价沿用论文报价中的加价项：上一期未运行的燃气、生物质或核电机组，按每 MWh 计 `startup_cost`。单列为 `startup_adder_resource`（附表 P0-6 Q9）。
  - VoLL：doctoral 取 8000；corrected 取 `market.voll_gbp_per_mwh`，默认 10000（附表 Q7）。该参数已加入 PSM 清单。
  - 缺电按记录的 blackout 计价，头条保持论文口径（附表 Q4）；A2 的隐藏缺口进 stress 账，不计入 VoLL。
  - 储能报价支付已经包含磨损，作为结算转移支付单列，不再进入 operating。此前磨损被计了两次。
- 内核逐期把成本项和结算项写入 `RealisationLog` 的 `COST_COLUMNS`（只在内存中，不写入账本）。适配层汇总出以下扩展字段：
  - `physical_operating_cost_detail_gbp`；
  - `market_settlement_components_gbp`：当期实际的转移支付，含当期储能报价支付、论文储能费跨期残留 `storage_fee_carry_residual`，以及与保留成本列的对账 `reconciliation`；
  - `market_rule_diagnostics`：doctoral 的已知偏差，包括 `unrecorded_vre_mwh`、`non_vre_double_counted_mwh`、`storage_fee_carry_gbp`、`vre_skim_leak_mwh`、`vre_skim_to_electrolysis_mwh`，以及 corrected 的 `phantom_surplus_mwh`；
  - `market_rule_set`：规则集 sha、字段、内核树 sha、存储报价基准归属和 VoLL。
- `physical_operating_cost_components_gbp` 的两个键名不变。账本 semantic metadata 记录规则集 id 和 sha。
- zones.json 新增三条规则：`*::*market_rule_set*` 划为 identity；`*::*market_rule_diagnostics*` 和 `*::*market_settlement_components*` 划为 accounting。
