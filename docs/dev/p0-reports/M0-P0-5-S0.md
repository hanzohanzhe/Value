## 6 偏差

1. 研究包按标签和 manifest sha 识别，不按 pack id。原因：发布版保留了原 id，草稿中的 `-public1` id 不是发布版。
2. golden 中增加了计划没有写明、但计划要求其作用的 `kernel_recorded`（monkeypatch 的真实记录）。该条目使用 D3 项目（value_101_day，48 期），指向各个包运行，因此只覆盖 48 期。全年的内核输入由 oracle 覆盖，toy 测试证明 oracle 与真实内核一致。
3. 为满足 50 KB 上限，哈希取 12 位（48 bit 变化检测足够），VRE 内核限值只存汇总摘要。逐站诊断可以在 S0 提交上用 `show --pack` 重新生成。
4. P6-03 中内核 Connection 错位是否也属于 A5 的两轨修复，DECISIONS 没有明说。基线只在 note 中标明「由 S4/S5 负责人决定并记录」，不替科学语义做主。
