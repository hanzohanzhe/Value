### 2.1 三类 gate（附表 P0-4 Q5）

- **run 不变量**：`run_invariants.py` 的 severity 改为 `gate`，不再标“report_only_until_p0_4_s7”。
- **能量平衡**：gate 是决策 A2 的能量平衡账，不是原始边界残差。
  - oracle 在可评估的声明边界上逐期计算 `closing = raw − 记录的 blackout + 缺口`，结果写入新增段 `balance_account`，对应检查为 `period.balance_account`。
  - 单纯的缺电一定闭合，只算 stress event；记入缺口后仍为正的残差算未闭合时段。
  - gate 所含检查为 `ENERGY_BALANCE_GATE_CHECKS`：finite、self_report、surplus_conservation、adjustment_share、balance_account。
  - oracle 自己的 `status`（原始边界判定）不变，作为证据写入 `energy_balance.raw_boundary_status`。
  - 没有可评估边界的旧账本沿用包络判定，永远不会是 passed。
- **储能吞吐不变量**（P0-6 S8 已合入，所以立即生效）：
  - oracle 新增 `storage` 段，由 `storage_energy_audit` 与 `storage_state` 联表得到四项检查：
    - `storage.rated_power`
    - `storage.single_direction`
    - `storage.soc_bounds`
    - `storage.soc_identity`
  - 联不上的审计行另报 `storage.audit_coverage`。
  - 没有储能行时为 `not_applicable`；有储能但没有审计表时为 `not_evaluated`。
  - DEV-BAL-03 的年末丢弃量作为证据写入 `year_end_discarded_mwh`。
