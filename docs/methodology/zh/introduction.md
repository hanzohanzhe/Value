# 模型框架

VALUE 将电力系统的逐时运行与年度资产变化联系起来。每个模型年先用在役发电、储能和输电容量计算供需平衡，再将运行收入、成本和可扩张容量传入投资规则，形成下一年的资产组合。研究的主要输出为发电与储能运行量、供电缺口、系统资源成本、碳排放以及新增和退役容量。

## 时间与空间表示

VALUE 的运行时间步长为 0.5 小时，每个模型年包含 17,520 个时段。功率以 MW 表示，期间电量以 MWh 表示，期间电量等于功率乘以时间步长。年度投资在一个完整运行年结束后更新，研究期内的资产变化由这些年度更新依次产生。

全国模型把英国电力系统表示为单个供需节点，并通过边界报价表示外部电力交换。分区模型进一步给定资源和需求的节点位置，以及节点间走廊的容量。两个分区研究配置分别采用 23 区、22 条走廊，以及 11 区、14 条计算走廊；相应的需求分配、资产映射和边界容量与各自配置共同使用。

## 年度计算结构

年度运行由初始资产、建设管线、需求与天气共同确定。年初先推进到期建设项目，再构造各技术的可用出力和边界交换输入；选定的调度模块据此计算本年的运行结果。年末投资规则使用运行结果提出新增与退役容量，并将建设周期和规划成功率作用于新增项目。

```text
读取初始资产 建设管线 需求 天气 技术成本和研究参数
for 每个模型年:
    推进建设管线并更新本年在役资产
    构造期间需求 可用发电量和边界交换输入
    执行选定的年度调度方法
    计算年度收入 成本和新增容量上限
    形成投资与退役决策
    更新下一年的资产和建设管线
输出各年运行结果和资产组合
```

调度方法通过共同的输入和年度输出连接投资环节。当前分阶段市场、R029 全国研究算法、全国联合出清和完全预见线性规划各自规定报价、储能调度及成本计算方式。第四至第六章给出年度市场与投资方法，第七章给出传输约束，第八章给出完全预见与水文计算。

## 数据与研究配置

研究输入由需求、气象、初始资产、技术经济参数、建设项目和边界交换组成。第二章说明各数据文件的内容、时间范围与单位，第三章说明天气到可用出力的转换。每章在相关计算步骤后给出数据名称和实现函数，使输入处理与数学设定能够直接对应。

R029 全国研究采用日历修正的数据包和对应的年度投资规则。分区研究采用其区域映射与边界输入。各章按这些研究配置说明初始条件和参数，教学示例则使用随安装提供的合成数据。
